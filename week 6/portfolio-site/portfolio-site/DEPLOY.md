# Get the site live (5 minutes)

## Deploy on Netlify — no account setup beyond signing in
1. Go to https://app.netlify.com/drop
2. Drag the whole `portfolio-site` folder (unzipped) onto the page
3. Netlify gives you a live URL immediately (e.g. `random-name-123.netlify.app`) — that's your live site for the crit
4. (Optional) In Site settings → change site name to something like `ahmed-elgharably.netlify.app`

## Before you send it for review, fill these in
- `cellula.html` — swap `PASTE-YOUR-HUGGINGFACE-SPACE-URL-HERE` for your real Space URL from Week 8
- `contact.html` — swap the GitHub / LinkedIn / resume placeholder links
- Any `[ADD: ...]` dashed box — real screenshots/diagrams, or leave as-is for now (an "ugly version" is allowed to have gaps — just don't hide that they're gaps)
- The `[metric — ...]` stat boxes — your real numbers if you have them yet

## Then run Week 7
Send the live URL + your one-line claim to a reviewer using the message and feedback log from earlier — that part hasn't changed, it just needed a real site to point at.
